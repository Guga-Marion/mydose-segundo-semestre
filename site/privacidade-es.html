Hola Usuario, gracias por acceder a la aplicación MyDose. My Dose LLC tiene el compromiso de cumplir las leyes que protegen la privacidad de los datos de los Usuarios y del público en general. Para prestar los servicios relacionados con la aplicación MyDose, es necesario tratar y compartir datos personales. AL UTILIZAR LA APLICACIÓN MYDOSE, EL USUARIO ACEPTA TÁCITA E ÍNTEGRAMENTE LAS DISPOSICIONES AQUÍ CONTENIDAS.

Capítulo IDisposiciones Generales

1.1. La aplicación MyDose considera de suma importancia la relación con sus Usuarios y sus datos personales. Esta Política de Privacidad fue elaborada para comunicar nuestras prácticas de recopilación, uso y divulgación de información.

1.2. La información personal son datos proporcionados por los Usuarios que pueden utilizarse para identificarlos individualmente.

1.3. La información personal sensible incluye datos sobre origen racial o étnico, convicciones religiosas, opiniones políticas y datos de salud, conforme lo estipulado por la Ley 13.709/18 (LGPD).

1.4. AL UTILIZAR LA APLICACIÓN MYDOSE, USTED AUTORIZA LA RECOPILACIÓN, EL USO Y LA DIVULGACIÓN DE INFORMACIÓN SOBRE USTED, EN LOS TÉRMINOS DE ESTA POLÍTICA.

1.5. La aplicación MyDose opera de conformidad con la legislación brasileña, incluyendo la Ley n.º 12.965/2014 (Marco Civil de Internet) y la Ley n.º 13.709/2018 (LGPD).

1.6. En caso de dudas, contáctenos por el correo contact@mydoseapp.com.

1.7. Esta Política describe qué información puede recopilarse sobre los Usuarios y cómo puede utilizarse.

Capítulo IIInformación Recopilada

2.1. Datos recopilados de los Usuarios:

  • Nombre completo
  • Dirección de correo electrónico válida
  • Fecha de nacimiento
  • Edad
  • Información de salud física, bienestar mental, presupuesto personal y nutrición

2.1.1. Los datos personales se recopilan en diversas circunstancias, incluyendo el registro en la aplicación y la activación de funcionalidades.

2.1.2. También se recopilan datos personales sensibles, tales como datos de actividad física, información médica y de salud provenientes de dispositivos conectados (Google Fit, Apple Health, Samsung Health, Strava, Garmin, etc.).

2.1.3. Los Usuarios pueden optar por conectar y compartir información de aplicaciones asociadas con MyDose.

2.1.4. La información recopilada por socios y terceros está sujeta a sus propios términos y políticas.

2.2. Datos recopilados de los Usuarios Líderes:

  • Nombre completo
  • Dirección de correo electrónico válida
  • Teléfono
  • Identificación fiscal (CPF o CNPJ)
  • Dirección completa
  • Datos de tarjeta de crédito

2.3. La recopilación de datos de menores se realizará mediante el consentimiento del Responsable.

2.4. Datos obtenidos mediante las API de Google. Cuando un Usuario Líder opta por conectar su cuenta de Google, MyDose solicita acceso a los siguientes ámbitos de la API de Google:

  • https://www.googleapis.com/auth/calendar.events — para crear eventos de calendario (con enlace de Google Meet) en el Google Calendar del profesional cuando se agenda una consulta en línea en la plataforma.
  • https://www.googleapis.com/auth/userinfo.email — para identificar y mostrar qué cuenta de Google fue conectada.

El tratamiento de todos los datos obtenidos mediante estas API de Google se rige exclusivamente por el Capítulo XIV (Google User Data — Limited Use) a continuación, que prevalece sobre cualquier disposición en contrario de esta Política.

Capítulo IIICómo Usamos la Información

3.1. MyDose utiliza la información recopilada para:

  • a) Identificar y registrar Usuarios y prestar los servicios de la aplicación
  • b) Garantizar que el contenido se presente de la forma más eficiente
  • c) Realizar mejoras generales en la aplicación
  • d) Ofrecer a los Administradores de RR.HH. acceso a los datos para análisis e informes
  • e) Contactar y notificar a los Usuarios sobre cambios en la plataforma
  • f) Realizar investigaciones estadísticas
  • g) Alimentar la base de datos Data Lake de MyDose
  • h) Fines promocionales o de marketing
  • i) Desarrollar soluciones personalizadas para una vida más saludable

3.2. La información adicional no personal puede utilizarse para cualquier finalidad.

3.3. MYDOSE MANTIENE LOS REGISTROS DE ACCESO A INTERNET BAJO CONFIDENCIALIDAD, EN UN ENTORNO CONTROLADO Y SEGURO, CON CIFRADO EN TRÁNSITO.

3.4. La información médica sensible no se utilizará en decisiones futuras de suscripción o siniestros.

3.5. Los servicios de MyDose no están destinados a diagnosticar, curar, mitigar, tratar o prevenir ninguna condición, ni sustituyen la atención médica profesional.

3.6. Los usos descritos en los ítems 3.1(d), 3.1(f), 3.1(g), 3.1(h) y 3.2 NO se aplican a los datos obtenidos mediante las API de Google. Esos datos se utilizan únicamente según lo descrito en el Capítulo XIV.

Capítulo IVCompartición de Información

4.1. MyDose no divulga a terceros ninguna información proporcionada por el Usuario, excepto:

  • a) Para cumplir una obligación legal o prevenir fraudes
  • b) Para proteger los derechos, la propiedad o la seguridad de MyDose
  • c) Con autoridades policiales o gubernamentales
  • d) Mediante notificación y consentimiento previos del Usuario
  • e) Por acción del propio Usuario, como compartir con Líderes de Comunidad
  • f) Para investigación estadística o autoral
  • g) Con empresas terceras prestadoras de servicios en conformidad con estándares de privacidad
  • h) Con agentes, contratistas o prestadores de servicios terceros
  • i) Con servidores terceros contratados que almacenan la base de datos (Google Cloud Platform, Supabase)
  • j) En caso de venta, fusión o reestructuración empresarial

4.2. Compartición internacional. MyDose utiliza servicios de Google Cloud Platform para almacenar y procesar datos, que pueden transferirse a los Estados Unidos.

4.3. Compartición con IA. Los datos de los Usuarios (excluidos los datos obtenidos mediante las API de Google) pueden compartirse mediante integración de API con Gemini (Google AI) para informes, automatización de procesos e interacciones automatizadas. Los datos obtenidos mediante las API de Google nunca se transmiten a servicios de IA, conforme al Capítulo XIV.

4.4. No divulgación. Salvo en las situaciones anteriores, MyDose no divulgará ninguna información personal.

4.5. EL USUARIO TIENE DERECHO A NO ACEPTAR ESTOS TÉRMINOS Y A ELIMINAR SUS DATOS.

4.6. Al aceptar estos términos, el Usuario autoriza la compartición de datos. El Usuario puede revocar el consentimiento en cualquier momento, incluso desconectando su cuenta de Google.

4.7. MyDose conservará los datos del Usuario mientras este permanezca registrado o mientras exista un interés legítimo de la empresa.

4.8. La compartición permitida por los ítems 4.1(f), 4.1(g), 4.1(h) y 4.3 NO se aplica a los datos obtenidos mediante las API de Google, salvo cuando sea estrictamente necesario para proveer la funcionalidad orientada al usuario, según se detalla en el Capítulo XIV.

Capítulo VCookies

5.1. Una cookie es información almacenada localmente en el dispositivo del Usuario que contiene datos sobre sus actividades en Internet.

5.2. Cookies utilizadas:

  • Cookies de Rendimiento: recopilan información anónima sobre el uso de la plataforma
  • Cookies Funcionales: proporcionan una mejor experiencia de navegación

5.3. El acceso a las cookies termina cuando el Usuario cierra el navegador. Puede aceptar o rechazar cookies en la configuración del navegador.

5.4. Se requiere la aceptación del Usuario antes del uso de cookies.

5.5. Si opta por rechazar las cookies, el acceso a la mayor parte de la información disponible puede verse comprometido.

Capítulo VIAcceso y Corrección de Información Personal

6.1. MyDose adoptará todas las medidas adecuadas para actualizar y corregir la información personal identificable.

6.2. El Usuario tiene derecho a acceder, modificar, corregir y eliminar sus datos en cualquier momento.

6.3. Es responsabilidad del Usuario mantener su información personal actualizada.

6.3.1. El Usuario es responsable de la información ingresada en la aplicación, afirmando que ha revisado su exactitud, incluso cuando la información sea extraída por inteligencia artificial.

6.4. El Usuario tiene derecho a acceder a su información personal en los términos de la Ley n.º 12.965/2014 y la Ley n.º 13.709/2018, contactando a contact@mydoseapp.com.

6.5. MyDose adopta todas las medidas necesarias para proteger la información personal contra pérdida, uso indebido y acceso no autorizado, con cifrado y estándares rigurosos de seguridad.

6.6. El Usuario es responsable de la protección de sus contraseñas y credenciales de acceso.

Capítulo VIINotificación de Modificaciones de la Política de Privacidad

7.1. MyDose puede modificar la Política de Privacidad periódicamente. En caso de cambios en el uso de información personal, los Usuarios serán notificados mediante anuncios en la plataforma o por correo electrónico.

7.2. El uso continuado de los servicios tras cualquier cambio constituye la aceptación de la Política modificada.

7.3. Pueden ocurrir ajustes menores sin previo aviso.

Capítulo VIIIUso de Funcionalidades de Inteligencia Artificial (IA)

Nuestra aplicación puede ofrecer funcionalidades opcionales basadas en servicios de Inteligencia Artificial de terceros (por ejemplo, Gemini / Google AI) para ayudar en la generación de resúmenes o sugerencias de salud.

Compartición de datos: Al optar por usar estas funcionalidades, entradas de texto específicas o datos explícitamente seleccionados por usted pueden transmitirse al proveedor de IA para su procesamiento. Los datos obtenidos mediante las API de Google (como datos de Google Calendar) quedan excluidos y nunca se transmiten a servicios de IA.

Consentimiento: Al usar estas funcionalidades de IA, usted consiente esta transferencia de datos.

Aviso: Todo contenido generado por IA tiene carácter meramente informativo y es revisado por su profesional de salud. No constituye asesoramiento médico.

Retención de datos: No permitimos que los proveedores de IA de terceros utilicen sus datos personales para entrenar sus modelos.

9.1.1. El Usuario puede optar por darse de baja utilizando el opt-out o solicitando la eliminación vía contact@mydoseapp.com.

9.1.2. Los correos administrativos relacionados con el mantenimiento de la cuenta no pueden cancelarse.

9.1.3. El uso de MyDose para Spam está absolutamente prohibido.

9.2. Se garantiza la máxima confidencialidad en el tratamiento de las direcciones de correo de los Usuarios.

9.2.1. Se garantiza al Usuario la posibilidad de eliminar su dirección de correo electrónico.

Capítulo XProhibiciones

10.1. MyDose se reserva el derecho de rechazar o eliminar cualquier conexión que contenga información incorrecta o afirmaciones infundadas.

Capítulo XISeguridad de la Información Personal

11.1. La aplicación MyDose utiliza cifrado de datos. La información está alojada en servidores en los Estados Unidos, con acceso solo por empleados autorizados.

11.2. Si MyDose tiene conocimiento de cualquier violación de seguridad, notificará inmediatamente a los Usuarios afectados.

11.3. MyDose puede copiar, divulgar, distribuir, incorporar y usar materiales y datos con fines comerciales o no comerciales, respetando esta Política. Esta disposición NO se aplica a los datos obtenidos mediante las API de Google, que se rigen exclusivamente por el Capítulo XIV.

11.4. El Usuario será responsable de indemnizar a MyDose por los costos derivados de violaciones de esta Política.

11.5. MyDose coopera con las autoridades que soliciten la identificación de personas que violen estas disposiciones.

11.6. Esta Política trata únicamente del uso y la divulgación de información recopilada por MyDose. MyDose no controla las políticas de privacidad de terceros.

12.2. Los datos obtenidos mediante las API de Google nunca se utilizan para marketing, publicidad o cualquier finalidad promocional, conforme al Capítulo XIV.

Capítulo XIVGoogle User Data — Limited Use

El uso y la transferencia por parte de MyDose de cualquier información recibida de las API de Google — incluyendo los ámbitos calendar.events y userinfo.email — se rigen por la Google API Services User Data Policy, incluidos los requisitos de Limited Use.

Específicamente, los datos obtenidos mediante las API de Google se utilizan únicamente para proveer y mejorar las funcionalidades orientadas al usuario para las cuales el usuario concedió acceso. El ámbito calendar.events se usa solo para crear eventos de calendario (con enlace de Google Meet) en el Google Calendar del profesional cuando se agenda una consulta en línea en la plataforma. El ámbito userinfo.email se usa solo para identificar y mostrar qué cuenta de Google fue conectada.

MyDose no:

  • utiliza datos de usuarios de Google para publicidad, marketing o cualquier finalidad promocional;
  • vende datos de usuarios de Google, ni los transfiere a terceros, salvo cuando sea necesario para proveer o mejorar la funcionalidad orientada al usuario, para cumplir la ley aplicable, o como parte de una fusión o adquisición con aviso al usuario;
  • usa o transfiere datos de usuarios de Google para desarrollar, mejorar o entrenar modelos generalizados o no personalizados de inteligencia artificial y/o aprendizaje automático, incluidos servicios de IA de terceros como Gemini;
  • permite que humanos lean datos de usuarios de Google, salvo cuando: (a) el usuario otorgue consentimiento previo explícito; (b) sea necesario por motivos de seguridad; (c) sea exigido para cumplir la ley aplicable; o (d) los datos estén agregados y anonimizados y se usen para operaciones internas.

Este Capítulo XIV prevalece sobre cualquier disposición en contrario de esta Política. Las disposiciones de los Capítulos III, IV, VIII, XI y XII relativas a marketing, agregación de datos, Data Lake, uso comercial, compartición con terceros y procesamiento por IA no se aplican a los datos obtenidos mediante las API de Google.

Los usuarios pueden revocar en cualquier momento el acceso de MyDose a sus datos de Google desconectando su cuenta de Google dentro de la aplicación, o mediante la página de permisos de la Cuenta de Google.

Google API Services User Data Policy

MyDose's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements. MyDose does not use or transfer data obtained through Google Workspace APIs to develop, improve, or train generalized artificial intelligence and/or machine learning models.
